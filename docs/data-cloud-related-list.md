# 04 — Create Data Cloud Related List (Contact)

## Goal
Create a Data Cloud Related List so ExternalReservation records can appear on Contact.

## Setup Steps
1. Setup → Object Manager → Contact
2. Data Cloud Related List → New
3. Data Cloud Object: ExternalReservation
4. Child Relationship Name: Reservations
5. Related List Label: Reservations
