
# Project Overview — Coral Cloud Resort (Data 360 + Agentforce)

## Problem Statement
Coral Cloud Resorts uses an external reservation system (Reserv-o-matic). Reservation details are not available inside Salesforce Contacts. Staff must check multiple systems, slowing down check-ins.

## Solution
Use Salesforce Data 360 (Data Cloud) to ingest external reservations and unify identity with Salesforce Contacts. Display the reservation records inside the Contact page and enable Agentforce actions using unified data.

## Result
✅ Reservations appear directly inside Contact record  
✅ Unified guest identity created using Identity Resolution  
✅ Data becomes AI-ready for Agentforce automation

## Business Impact
- Faster check-in process
- Unified customer view for staff
- Improved personalized guest service
